# Changelog

## 1.1.0

- **Done tab:** everything finished in the last two weeks, with scores once graded.
- **Uncheck anything:** tap the check again or Undo. Checked items stay in place until the list reloads, so a mis-tap is easy to fix. This works for work Canvas shows as submitted too.
- **Grades:** the Courses tab shows your current grade per class, open work, and recent scores, with new grades marked. Scores and "Missing" flags also show on items.
- **Reminder settings:** choose how early to be reminded, when (or whether) to get the nightly summary, and whether to be alerted about newly posted assignments.
- **App icon badge:** shows how many things are overdue or due today, where the phone supports it.
- **Self-updating Sync bookmark:** the bookmark loads the latest sync code each time. There's an all-in-one fallback for schools that block it.
- **Auto-update:** each copy pulls new versions daily and redeploys.

## 1.0.0

- First public release: calendar feed sync, Prep view, reminders, in-app setup, QR handoff to phone.
